🎵 Music Player App

Overview:
The Music Player App is an Android-based application developed using Java and Kotlin in Android Studio. It allows users to play, pause, skip, and manage audio files stored locally on their devices. The app provides a clean and intuitive user interface designed with XML layouts, offering a smooth and engaging playback experience without relying on external APIs or internet access.

🎯 Aim

To develop a fully functional music player application that enables users to browse and play audio files stored on their device using Android’s native MediaPlayer API.

🧠 Key Features

▶️ Play / Pause / Skip Controls: Smooth and responsive playback control using Android’s MediaPlayer.

🎚️ Seek Bar Integration: Displays and controls the current playback position.

🧾 Now Playing Display: Shows the current song title and artist dynamically.

🔁 Repeat and Shuffle Modes: Adds flexibility for continuous and randomized playback.

📂 Local Storage Access: Scans and lists available songs stored on the device.

🎨 Interactive UI: Designed using XML with responsive layouts for easy navigation.

🧩 Technologies Used

Programming Languages: Java, Kotlin

Framework / IDE: Android Studio

Core Android Components:

MediaPlayer API

Notification Channel

Runtime Permissions

XML Layout Design

⚙️ System Requirements

Software:

Android Studio (latest version)

Java Development Kit (JDK 8 or above)

Android SDK and Emulator / Physical Device

Hardware:

10 GB free storage space

🏁 Conclusion

The Music Player App successfully demonstrates the creation of an Android media application that efficiently plays local audio files using Android’s native capabilities. It strengthened understanding of MediaPlayer, UI design, and Android permissions, providing a strong foundation for developing more advanced and interactive mobile applications.
